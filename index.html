Help

Connect OBS automatically

Skip the manual steps below. This connects to OBS over its WebSocket and builds the Overlay scene and browser source for you.

How do I add the overlay to my streaming software?

  1. Open your Streaming Software of choice
  2. Create a new browser source
  3. Set the source to: http://localhost:3000
  4. Set the resolution to: 1920px (width) by 1080px (height) Standard 1080p
  5. Click OK
  6. Right click the source you just made
  7. Go to the "Transform" option
  8. Then click "Fit to screen"

How do I add the highlight reels to my streaming software?

  1. Open your Streaming Software of choice
  2. Create a new browser source
  3. Set the source to: http://localhost:3001
  4. Set the resolution to: 1920px (width) by 1080px (height) Standard 1080p
  5. Click OK
  6. Right click the source you just made
  7. Go to the "Transform" option
  8. Then click "Fit to screen"

How do I create my own overlay?

  1. Create a folder for your overlay and make sure it contains an overlay.html file at the root.
  2. Build your layout in overlay.html at 1920x1080 and include the Socket.IO client script: /socket.io/socket.io.js.
  3. Connect to Rocket Cast with const socket = io(); then listen for live game packets with socket.on("state", (packet) => { ... }).
  4. Add an overrides listener so Rocket Cast controls can update your overlay. This is required: socket.on("overrides", (data) => { ...apply values to your elements... }).
  5. Inside your state and overrides handlers, update your DOM elements by selector (team names, scores, clock, player bars, etc.).
  6. In Rocket Cast, open the Overlays tab and click Upload Overlay Folder, then select your overlay folder.
  7. Launch your uploaded overlay and test it in-game.
  8. If values are not changing, check your selector names and confirm both handlers exist: state and overrides.
